# Повторная проверка реализации

Проверено на parquet и starter, предоставленных организаторами. Это техническая проверка работоспособности и объяснимости; ground truth для оценки точности отсутствует.

| Обнаруженная проблема первой версии | Исправление / проверка |
|---|---|
| Средние/медианы переводов считались по агрегированным рёбрам | Статистики по transactions, отдельный регрессионный тест |
| Нулевой признак получал положительный percentile | Нулевой сигнал нормализуется в 0 |
| Изолят мог получить роль coordinator | Eligibility, нулевая structural priority, сохранение всех изолятов |
| Не проверялось совпадение сумм/count в edges и transactions | Полная сверка по парам, типам, суммам и количествам |
| `astype(bool)` считал строку false истинной | Явный разбор boolean |
| Временная эвристика переиспользовала один исходящий платёж | FIFO с ограничением сумм и отдельными окнами |
| Эвристика ошибочно заявляла факт перенаправления денег | Подписи указывают временное сопоставление и точность дат |
| Сильный выход при слабом входе мог автоматически давать transit | Диапазон для non-seed и отдельное условие seed |
| Рейтинг дублировал объяснение роли | Реальные взвешенные слагаемые, сумма равна priority_score |
| Нет полного explain_node | Метрики, role/priority contributions и ограничения; использует UI |
| UI не имел полноценного выбора кластеров/срезов | Эго-граф, кластер, крупнейшая компонента, вся сеть, фильтры, стрелки, hover |
| GID мог округляться в JavaScript | Строковые GID на границе UI; тест int64 >2^53 |
| Не запускались pipeline и тесты | Рабочая .venv, зафиксированное окружение, 39 проходящих проверок |
| README не описывал реальные формулы | Формальные условия, веса, confidence, priority и measured runtime |

## Подтверждённые обязательные результаты

- Pipeline выполняется одной командой на реальных данных, существенно быстрее 5 минут.
- Ровно 2 248 строк с GID, допустимой ролью, score в [0,1], непустым evidence ≤200 символов.
- Сохранены 19 изолированных seed; 444 граничных узла не классифицированы terminal.
- Все узлы имеют кластер; суммы считаются по исходным рёбрам без двойного учёта.
- Top-50 отсортирован; объяснения привязаны к слагаемым приоритета.
- Поиск GID, boundary-карточка, пустые связи изолята и режим кластера проверены UI-тестами; поиск длинного GID и предупреждение depth=4 дополнительно проверены в браузере.
- Базовые финансовые/топологические признаки совпадают со starter организаторов.
- Стресс-тест имеет воспроизводимый random baseline из 30 выборок.

## Что остаётся неопределённым

Роли — экспертные гипотезы. Отсутствие ground truth исключает заявление о точности классификации. Betweenness приближённая; веса/пороги могут быть предметом обсуждения с AML-аналитиком. Дневные даты не позволяют доказывать внутридневной транзит. 67 кластеров и 9 сообществ с несколькими seed зависят от выбранной проекции, а не являются единственно правильным разбиением.

Модель и UI работают локально. Публикация, commit и push не выполнялись. Исходные архивы не изменены.
